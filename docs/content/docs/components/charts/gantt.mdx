Gantt is an SVG timeline for ERP / MES style planning. Pass `data` (tasks). Optional `resources`, `dependencies`, `calendar`, and `zoom` unlock machine planning, links, working time, and scale levels.

The legacy API stays valid: `title`, `description`, `data`, `pagination`, and `config` still work.

## Import

```tsx
import { Gantt } from "@harjs/react-ui";
```

```tsx
<Gantt
  data={tasks}
  resources={resources}
  dependencies={dependencies}
  defaultZoom="day"
  onTaskChange={handleTaskChange}
/>
```

## Interaction

- Drag a bar to reschedule; use edge handles to resize.
- `Ctrl/Cmd + click` and `Shift + click` for multi-select.
- `Ctrl/Cmd + wheel` changes zoom (`hour` → `quarter`).
- `Ctrl/Cmd + Z` / `Y` undo and redo when task changes are applied.
- Right-click fires `onContextMenu(task, event)` — menus stay in the host app.

## Working calendar

```tsx
<Gantt
  data={tasks}
  calendar={{
    workingDays: [1, 2, 3, 4, 5],
    shifts: [{ start: "08:00", end: "17:00" }],
    holidays: ["2026-10-29"],
  }}
/>
```

Non-working days are striped on the timeline. Drag snap respects `snap` and working time when possible.
