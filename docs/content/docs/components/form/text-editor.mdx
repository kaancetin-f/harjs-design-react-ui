---
title: Text Editor
description: Rich text editing with an HTML value.
---

Text Editor is a controlled rich-text field. The value is an HTML string updated through `onChange`.

## Import

```tsx
import { TextEditor } from '@harjs/react-ui'
```

## Usage

<Example>
  <TextEditorBasic />
</Example>

## Examples

### Mentions

Pass `dynamicList` to open a list when the user types `triggerKey` (default `@`). Filter by typing, move with `↑↓`, select with `Enter`, and close with `Esc`. `onTagged` receives the selected items. `color` paints the inserted mention chip with a design token (`purple` in this example).

<Example>
  <TextEditorMentions />
</Example>

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `value` | `string` | — | Controlled HTML content |
| `onChange` | `(value?: string) => void` | — | Called with HTML (or `undefined` when empty) |
| `height` | `number` | — | Editor iframe height in px |
| `placeholder` | `string` | — | Floating label |
| `variant` | `"filled" \| "outlined" \| "dashed" \| "borderless"` | `"outlined"` | Visual style (`surface` is not supported) |
| `color` | `"blue" \| "purple" \| "pink" \| "red" \| "orange" \| "yellow" \| "green" \| "teal" \| "cyan" \| "gray" \| "white"` | `"gray"` | Theme color |
| `border.radius` | radius tokens | `"4"` | Corner radius |
| `name` | `string` | — | iframe name |
| `disabled` | `boolean` | — | Disable editing |
| `validation` | `{ text?: string }` | — | Error message |
| `dynamicList` | `{ render; triggerKey?; color?; onTagged }` | — | Optional mention list. `color` styles the inserted `@` chip |
