---
title: Date Picker
description: Select a single date or a date range.
---

Date Picker is controlled. Single mode uses a date string. Range mode uses `{ start, end }` with `multiple` and `direction`. Styling tokens match Input (`variant`, `color`, `size`, `border`).

## Import

```tsx
import { DatePicker } from '@harjs/react-ui'
```

```tsx
<DatePicker value={value} onChange={setValue} />
<DatePicker multiple direction="row" value={range} onChange={setRange} />
```

## Examples

### Time

`config.isClock` adds a time picker next to the calendar.

<Example>
  <DatePickerTime />
</Example>

### Time only

`config.isOnlyClock` hides the calendar and shows only the clock. With `multiple`, the end clock disables hours and minutes before the start time.

<Example>
  <DatePickerClockOnly />
</Example>

### Range

`multiple` selects a start and end date. `direction` lays the two fields out in a row or a column.

In range mode, the end picker cannot go before the start:

- Days before the start date are disabled on the end calendar
- On the same day (or with `isOnlyClock`), hours and minutes before the start time are disabled
- Native pickers set `min` from the start value; invalid end values are clamped to start

<Example>
  <DatePickerRange />
</Example>

### Min (separate pickers)

When you use two single DatePickers, pass the start value as `min` on the end picker. Days and times before `min` are disabled; if start moves past end, end is clamped up.

```tsx
<DatePicker value={start} onChange={setStart} />
<DatePicker value={end} onChange={setEnd} min={start} />
```

<Example>
  <DatePickerMin />
</Example>

### Disabled

<Example>
  <DatePickerDisabled />
</Example>

### Validation

`validation.text` shows an error message and paints the field red. Clear it when the value is valid.

<Example>
  <DatePickerValidation />
</Example>

## Props

| Prop | Type | Default |
| --- | --- | --- |
| `value` | `string` or `{ start: string; end: string }` | — |
| `onChange` | `(value) => void` | — |
| `multiple` | `boolean` | `false` |
| `direction` | `"row" \| "column"` | — |
| `placeholder` | `string` | — |
| `variant` | `"filled" \| "surface-borderless" \| "outlined" \| "dashed" \| "borderless"` | `"outlined"` |
| `color` | `"blue" \| "purple" \| "pink" \| "red" \| "orange" \| "yellow" \| "green" \| "teal" \| "cyan" \| "gray" \| "white"` | `"gray"` |
| `size` | `"xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl"` | `"lg"` |
| `border.radius` | `"0" \| "2" \| "4" \| "6" \| "8" \| "12" \| "16" \| "20" \| "40" \| "full"` | `"4"` |
| `disabled` | `boolean` | — |
| `min` | `string` | — |
| `validation` | `{ text?: string; scrollTo?: boolean }` | — |
| `config.locale` | `Intl.LocalesArgument` | `"tr"` |
| `config.isClock` | `boolean` | — |
| `config.isOnlyClock` | `boolean` | — |
| `config.isShortcutButtons` | `boolean` | `true` |
| `config.isFooterButton` | `boolean` | `true` |

`surface` is not available — same as Input. When `multiple` is set, `direction` is required and `value` / `onChange` use `{ start, end }`. Use `min` on a single picker to block values before another picker’s value (e.g. end ≥ start).
